# AGENTS.md

Context for AI agents working on this repository. Read this first.

## What is this?

TypeScript SDK for the [EasySQL API](https://easysql.net). Wraps the API with a fully typed client generated from the OpenAPI spec.

## Stack

| Layer | Choice |
|---|---|
| Runtime | Bun (scripts, CI) |
| Language | TypeScript 5.5 (ES2022, ESM) |
| HTTP client | `openapi-fetch` |
| Type generation | `openapi-typescript` 7.x |
| Task runner | Makefile |
| CI | GitHub Actions |

## Project structure

```
.
├── src/
│   ├── api-types.ts       # Auto-generated from OpenAPI spec (do not edit by hand)
│   ├── client.ts           # createEasySQLClient() wrapper
│   ├── index.ts            # Public exports
│   └── test.ts             # Smoke test against the API
├── scripts/
│   └── generate.ts         # Downloads spec → runs openapi-typescript → writes api-types.ts
├── .github/workflows/
│   └── generate-sdk.yml    # Triggered via repository_dispatch or workflow_dispatch
├── Makefile                # help, install, generate, typecheck, build, test, clean, all
├── .env.example            # EASYSQL_API_URL (+ optional test credentials, commented out)
├── bun.lock
├── package.json
└── tsconfig.json
```

## Key files

| File | Role | Editable by hand? |
|---|---|---|
| `src/api-types.ts` | All API types (`paths`, `components`, `operations`) | ❌ Generated by `make generate` / CI |
| `src/client.ts` | `createEasySQLClient()` — thin wrapper over `openapi-fetch` | ✅ |
| `src/index.ts` | Re-exports client + types for consumers | ✅ |
| `src/test.ts` | Smoke test (login → me → dashboard → connectors) | ✅ |
| `scripts/generate.ts` | Orchestrates type generation (reads `.env` for API URL) | ✅ |
| `.github/workflows/generate-sdk.yml` | CI workflow | ✅ |

## How to work on this

```bash
cp .env.example .env           # set EASYSQL_API_URL
make install                   # bun install --frozen-lockfile
make generate                  # download spec → api-types.ts
make typecheck && make build   # validate + compile
bun run src/test.ts            # smoke test (uncomment credentials in .env)
```

## Public API

```typescript
import { createEasySQLClient } from "@clearsoft/easysql-sdk";

const api = createEasySQLClient({ baseUrl: "..." });
// or with auth:
const api = createEasySQLClient({ baseUrl: "...", accessToken: "..." });

const { data, error } = await api.POST("/v1/auth/login", { body: { ... } });
const { data } = await api.GET("/v1/auth/me");
```

## Endpoints

| Prefix | Methods | Paths |
|---|---|---|
| `/v1/auth` | POST, GET, PATCH, DELETE | login, register, refresh, me, change-password |
| `/v1/billing` | GET, POST | plans, checkout, portal |
| `/v1/connectors` | GET, POST, PUT, DELETE | list, create, `/{id}`, test |
| `/v1/dashboard` | GET | stats |
| `/v1/queries` | GET, POST | list, create, `/{id}` |
| `/` | GET | health check |

## CI workflow

- **Triggered by**: the EasySQL API repo via `repository_dispatch` (when the spec changes), or manually via `workflow_dispatch`
- **What it does**: checkout → `bun install` → `bun run generate` → `bun run typecheck` → `bun run build` → opens PR
- **URL variable**: reads `EASYSQL_API_URL` from GitHub Actions Variables, falls back to `https://api.easysql.net`

## .env reference

| Variable | Used by | Required? |
|---|---|---|
| `EASYSQL_API_URL` | `generate`, `test` | Yes |
| `EASYSQL_EMAIL` | `test` only | No (commented out by default) |
| `EASYSQL_PASSWORD` | `test` only | No (commented out by default) |
