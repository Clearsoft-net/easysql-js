# AGENTS.md

Context for AI agents working on this repository. Read this first.

## What is this?

TypeScript SDK for the [EasySQL API](https://easysql.net). Wraps the API with a fully typed client generated from the OpenAPI spec.

## Stack

| Layer | Choice |
|---|---|
| Runtime | Bun (scripts, CI) |
| Language | TypeScript 5.5 (ES2022, ESM) |
| HTTP client | `openapi-fetch` |
| Type generation | `openapi-typescript` 7.x |
| Task runner | Makefile |
| CI | GitHub Actions |

## How to work on this

```bash
cp .env.example .env           # set EASYSQL_API_URL
make install                   # bun install --frozen-lockfile
make generate                  # download spec → api-types.ts + client.ts + docs/API.md
make typecheck && make build   # validate + compile
make test                      # unit tests
```

## Public API

```typescript
import { createEasySQLClient } from "@clearsoft/easysql-sdk";

const api = createEasySQLClient({ baseUrl: "..." });
// or with auth:
const api = createEasySQLClient({ baseUrl: "...", accessToken: "..." });

// Named methods with full type safety:
const { data, error } = await api.login({ email: "...", password: "..." });
const { data: user } = await api.me();
const { data: connectors } = await api.listConnectors();
const { data: result } = await api.createQuery({ connector_id: "...", question: "..." });
```

## CI workflow

- **Triggered by**: the EasySQL API repo via `repository_dispatch` (when the spec changes), or manually via `workflow_dispatch`
- **What it does**: checkout → `bun install` → `make generate` → `make typecheck` → `make test` → `make build` → opens PR
- **URL variable**: reads `EASYSQL_API_URL` from GitHub Actions Variables, falls back to `https://api.easysql.net`
- **Retry**: spec download retries 3 times with exponential backoff
