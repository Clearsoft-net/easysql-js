# EasySQL SDK — TypeScript

Official TypeScript SDK for the [EasySQL API](https://easysql.net).

> ⚠️ **Auto-generated types.** The `src/api-types.ts` file is auto-generated by
> the [`generate-sdk.yml`](./.github/workflows/generate-sdk.yml) workflow.
> Manually opened pull requests to that file will be closed.

## Installation

```bash
npm install @clearsoft/easysql-sdk
```

## Usage

```typescript
import { createEasySQLClient } from "@clearsoft/easysql-sdk";

// Anonymous client (login, register)
const anon = createEasySQLClient({ baseUrl: "https://api.easysql.net" });

// Authenticated client
const api = createEasySQLClient({
  baseUrl: "https://api.easysql.net",
  accessToken: "your-access-token",
});
```

### Authentication

```typescript
// Login
const { data: token, error } = await anon.POST("/v1/auth/login", {
  body: { email: "user@example.com", password: "my-password" },
});

if (error) throw new Error(`Login failed: ${error}`);

const api = createEasySQLClient({
  baseUrl: "https://api.easysql.net",
  accessToken: token.accessToken,
});

// Get current user
const { data: user } = await api.GET("/v1/auth/me");
```

### Running queries

```typescript
// Send a natural language query
const { data: result } = await api.POST("/v1/queries", {
  body: {
    connectorId: "conn_abc123",
    question: "How many users signed up this month?",
  },
});

// List recent queries
const { data: history } = await api.GET("/v1/queries", {
  params: { query: { page: 1, per_page: 10 } },
});
```

### Managing connectors

```typescript
// Create a connector
const { data: connector } = await api.POST("/v1/connectors", {
  body: {
    name: "Production DB",
    type: "mysql",
    config: {
      dbType: "mysql",
      host: "db.example.com",
      port: 3306,
      database: "myapp",
      username: "readonly",
      password: "secret",
    },
  },
});

// List connectors
const { data: connectors } = await api.GET("/v1/connectors");
```

### Dashboard stats

```typescript
const { data: stats } = await api.GET("/v1/dashboard/stats");
```

## API Reference

All endpoints are fully typed. Use your editor's autocomplete on `api.GET()`, `api.POST()`, `api.PUT()`, `api.PATCH()`, `api.DELETE()`.

| Module | Endpoints |
|---|---|
| Auth | `/v1/auth/login`, `/v1/auth/register`, `/v1/auth/refresh`, `/v1/auth/me`, `/v1/auth/change-password` |
| Billing | `/v1/billing/plans`, `/v1/billing/checkout`, `/v1/billing/portal` |
| Connectors | `/v1/connectors`, `/v1/connectors/{id}`, `/v1/connectors/test` |
| Dashboard | `/v1/dashboard/stats` |
| Queries | `/v1/queries`, `/v1/queries/{id}` |

## Development

```bash
cp .env.example .env                 # configure API URL
bun install                           # install dependencies
make generate                         # download OpenAPI spec → src/api-types.ts
make typecheck                        # check TypeScript types
make build                            # compile to dist/
make test                            # run unit tests
make smoke                           # smoke test (needs credentials in .env)
```

Or use `make all` for the full pipeline.
